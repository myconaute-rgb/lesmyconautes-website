 Refonte graphique globale de la page
d'accueil
Je souhaite transformer uniquement la page d'accueil de mon site.
Les autres pages (Particuliers, Restaurateurs, Producteurs, Contact) ne doivent pas être
modifiées pour l’instant.
Le contenu, les fonctionnalités et la navigation doivent rester identiques. Cette première
itération a pour seul objectif de définir une nouvelle direction artistique .
La maquette que je joins est la référence graphique de cette refonte. Il s'agit de s’en
approcher au plus près, d'en retrouver l'esprit, le rythme, les proportions et le niveau de
qualité.
Les nouvelles photos et les ajustements de contenu feront l'objet de prompts séparés.
Objectif
Je souhaite que cette page d'accueil évoque immédiatement :
● une marque artisanale haut de gamme ;
● un univers gastronomique contemporain ;
● une entreprise agricole moderne et engagée ;
● un magazine éditorial consacré aux champignons ;
● une identité graphique forte, chaleureuse et mémorable.
Je ne veux surtout pas d'un design de startup, d'une landing page SaaS ou d'un template
générique.
Le site doit avoir énormément de personnalité.
Il doit être vivant, généreux, premium et donner envie de faire défiler toute la page.
Structure
Conserver la structure actuelle de la page d'accueil.
Conserver également l'ordre des sections tel qu'il apparaît dans la maquette de référence.

 Ne pas modifier :
● la navigation ;
● les liens ;
● les CTA ;
● les contenus ;
● les autres pages du site.
Cette étape concerne uniquement l'habillage graphique.
Direction artistique
Le style général doit évoquer un mélange de :
● magazine gastronomique ;
● identité de marque artisanale ;
● packaging premium.
Le design doit être très éditorial.
Chaque section doit avoir une forte présence visuelle.
Le rythme de lecture doit alterner naturellement entre :
● grands titres ;
● grandes images ;
● textes ;
● boutons cliquables ;
● espaces ;
● aplats de couleur “color bloc”
La page doit raconter une histoire.
Palette de couleurs
Construire la palette à partir des couleurs de la maquette.
Je souhaite que l'IA récupère automatiquement les couleurs dominantes afin de proposer un
premier rendu cohérent. Les codes hexadécimaux seront définis précisément dans une
étape ultérieure.
Le violet devient la couleur identitaire principale.

 Les fonds utilisent principalement un crème très clair plutôt qu'un blanc pur.
Les textes utilisent un brun très foncé presque noir.
Le rouge/orange est réservé aux accents graphiques.
Éviter totalement :
● les gris ;
● les dégradés ;
● les effets de verre (glassmorphism) ;
● le neumorphism.
Privilégier de grands aplats de couleur.
Ne jamais multiplier les couleurs fortes dans une même section.
Typographie
Utiliser exclusivement :
● Anton pour tous les grands titres ;
● Poppins pour tous les autres textes (paragraphes, menus, boutons, formulaires,
cartes, légendes, FAQ...).
Les grands titres deviennent de véritables éléments graphiques.
Ils doivent être :
● très grands ;
● très condensés ;
● très impactants ;
● principalement violets.
Comme dans la maquette, certains mots importants peuvent être affichés en italique afin
d'apporter du rythme.
Créer une hiérarchie très marquée entre :
● les titres principaux ;
● les titres de section ;
● les textes courants ;
● les boutons ;
● les légendes.
Le contraste typographique doit être très fort.

 Mise en page
Créer une mise en page beaucoup plus éditoriale.
Augmenter sensiblement :
● les marges latérales ;
● les espacements verticaux ;
● les respirations entre les sections.
Les éléments ne doivent jamais sembler collés les uns aux autres.
L'ensemble doit paraître plus haut de gamme uniquement grâce aux proportions et aux
espaces.
Créer une véritable alternance entre :
● grands aplats crème ;
● grands aplats violets ;
● grandes photographies ;
● espaces blancs.
Le rythme vertical doit être beaucoup plus marqué que sur le site actuel.
Images
Ne pas remplacer les images existantes.
Je fournirai un nouveau jeu de photographies dans une prochaine itération.
En revanche, adapter dès maintenant la mise en page afin que de futurs visuels puissent
occuper une place beaucoup plus importante.
Les images devront devenir l'un des principaux éléments du design.
Privilégier des mises en page pensées pour accueillir :
● des photos pleine largeur ;
● de grands portraits ;
● des photographies de récolte ;
● des photographies de cuisine ;
● des gros plans produits.

 Éviter les petites images perdues dans la page.
Les futures images devront naturellement trouver leur place.
Boutons
Redessiner tous les boutons.
Ils doivent paraître plus premium.
Utiliser Poppins.
Créer des boutons :
● plus généreux ;
● plus épais ;
● avec une hauteur confortable ;
● avec des coins moins arrondis (10 %) ;
● avec davantage d'espace intérieur.
Le bouton principal utilise le violet.
Le bouton secondaire possède un fond transparent avec un contour violet.
Les transitions restent très discrètes.
Cartes
Toutes les cartes doivent adopter un nouveau langage graphique.
Je ne souhaite pas encore modifier leur contenu.
Préparer simplement une présentation plus éditoriale.
Les cartes ne doivent plus ressembler à des cartes Bootstrap ou Material Design.
Elles devront être capables d'accueillir plus tard :
● une grande image ;
● un titre ;
● un texte ;
● un bouton.

 Titres
Chaque grande section doit posséder un titre spectaculaire.
Le titre devient un véritable élément graphique.
Très grand.
Très lisible.
Très impactant.
Principalement violet.
Avec éventuellement un mot en italique lorsque cela améliore le rythme visuel.
Icônes
Limiter fortement leur utilisation.
Si elles sont présentes :
● style simple ;
● monochrome ;
● aucune ombre ;
● aucun effet 3D ;
● aucun dégradé.
Espacements
Augmenter les espacements à tous les niveaux.
Entre les sections.
Entre les blocs.
Autour des titres.
Autour des boutons.

 Autour des cartes.
La page doit respirer.
Animations
Les animations doivent rester extrêmement discrètes.
Privilégier uniquement :
● des fondus ;
● de légers déplacements ;
● des transitions fluides.
Éviter :
● le parallaxe ;
● les zooms agressifs ;
● les animations spectaculaires.
Le mouvement doit uniquement accompagner la lecture.
Responsive
La version mobile ne doit pas être une simple réduction de la version desktop.
Les grands titres doivent conserver leur impact.
Les images doivent rester généreuses.
Les espacements doivent être préservés.
Les cartes peuvent naturellement passer sur une seule colonne.
L'expérience doit rester premium sur tous les formats.
Ce qu'il ne faut surtout pas faire
Ne pas modifier les textes.

 Ne pas modifier les CTA.
Ne pas modifier les liens.
Ne pas modifier la navigation.
Ne pas modifier les autres pages.
Ne pas remplacer les images.
Ne pas créer de nouvelles sections.
Ne pas simplifier la structure actuelle.
Ne pas transformer le site en landing page SaaS.
Ne pas utiliser Bootstrap ou Material Design comme référence visuelle.
Ne pas créer un design minimaliste froid.
Ne pas ajouter de dégradés modernes.
Ne pas utiliser de glassmorphism.
Ne pas utiliser de neumorphism.
Je souhaite que le site conserve son identité artisanale tout en gagnant énormément en
qualité graphique.
Résultat attendu
À la fin de cette première étape, je souhaite retrouver exactement la même page d'accueil,
avec les mêmes contenus et les mêmes fonctionnalités, mais entièrement repensée
graphiquement.
Le visiteur doit avoir l'impression que Les Myconautes disposent désormais d'une identité
visuelle digne d'une marque premium, éditoriale et artisanale, inspirée par la maquette de
référence, sans que le contenu ou la structure n'aient été modifiés.
